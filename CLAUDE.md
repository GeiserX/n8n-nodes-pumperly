# CLAUDE.md — n8n-nodes-pumperly

## Overview
n8n community node for Pumperly, providing real-time fuel and EV charging price data, station search by area/proximity, route planning, and geocoding within n8n workflows.

## Tech Stack
- TypeScript
- n8n community node SDK
- Vitest (test framework)
- Node.js (build via `package.json` scripts)

## Development
```bash
npm install
npm run build        # Compile TypeScript
npm run lint         # Lint source
npm test             # Run vitest suite

# Icon generation
node build-icons.cjs
```

## Architecture
- `nodes/` — Node implementations (Station, Route, Stats, Config, Exchange Rate, Geocode, Trigger)
- `credentials/` — Pumperly credential definition (instance URL only; no auth required)
- `tests/` — Vitest test suite
- `docs/` — Documentation and images

## Key Rules
- The Pumperly public API requires no authentication; credential stores only the base URL
- Supports 16+ fuel types (E5, E10, B7, LPG, CNG, EV, etc.)
- Follow n8n community node conventions for resource/operation patterns
- Package published to npm as `n8n-nodes-pumperly`
